# washing-done
Washing Done Cheltenham website

Static HTML, CSS and JavaScript website.

## GitHub Pages

1. Upload `index.html`, `style.css`, and `script.js` to the repository root.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, **main**, and **/(root)**, then save.
4. Open the GitHub Pages URL shown in Settings → Pages.

`README.md` is optional and does not affect the website.

Before publishing publicly, verify business details, prices, opening hours and remove any preview notices if appropriate.
